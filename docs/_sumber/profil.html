Proyek

JawaRustGo++ (JRG)

Bahasa pemrograman dengan pesan galat berbahasa Indonesia, ditulis dengan Rust. Satu program bisa dijalankan lewat interpreter, mesin virtual bytecode, atau dikompilasi jadi program native lewat LLVM. Dilengkapi pengelola proyek jrgm, pustaka standar, FFI ke dua belas bahasa, pembungkus aplikasi Android, JRG IDE, dan kelas Matematika × JRG.
