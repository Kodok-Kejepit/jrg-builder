JawaRustGo++ (JRG) is a programming language whose error messages explain where the problem is and how to get out of it. It is written in Rust, and its code looks like Rust and Go. One program runs through an interpreter, a virtual machine, a JIT, or compiles to a native program, and the answer is the same everywhere.

Errors you can read

A message names where the problem is, what went wrong, and the way out.

```sh $ jrgc prices.jrg kepentok di baris 2 waktu jalan. keterangannya di bawah. error: index [3] di luar batas — array ini isinya 3 elemen (index valid: 0..2, atau -1..-3 kalau mau hitung dari belakang) --> prices.jrg:2:5 | 2 | wok(prices[3]) | ^^^^^^^^^ ```

Messages are in Indonesian today ("index [3] is out of bounds — this array holds 3 elements; valid indices are 0..2, or -1..-3 counting from the end"). English messages are being written, and the language will be chosen with jrgm language en.

What is in the box

What you get once JRG is installed.

Four engines, a fifth on the way

An interpreter for trying things out, a faster bytecode VM (--vm), a JIT (--jit) that compiles hot code while it runs, and native compilation through LLVM (--emit-llvm). A fifth engine, WebAssembly, is being built so JRG programs run on the web.

{BUILTIN} built-in functions

Text, collections, files, time, JSON, regex, HTTP, SQLite, canvas, sound, and numerics. Search them with jrgc --cari.

The std/ library

37 modules (set, queue, heap, CSV, money, tables…) plus a 2D game engine, all written in JRG.

Other languages

Call C, C++, Rust, Go, Python, JavaScript, PHP, Lua, Java, Kotlin, .NET, and WebAssembly.

Projects and packages

jrgm creates projects, manages dependencies through git, runs tests, formats, and checks code.

All the way to your phone

Package a program as an Android APK with jrgm apk. There is also JRG IDE, which runs on the phone.
