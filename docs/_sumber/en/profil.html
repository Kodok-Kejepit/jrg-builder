Projects

JawaRustGo++ (JRG)

A programming language written in Rust, with error messages that explain the way out. One program runs through an interpreter, a bytecode virtual machine, a JIT, or compiles to a native program through LLVM; a fifth engine, WebAssembly, is being built. It comes with the jrgm project manager, a standard library, FFI to twelve languages, an Android app packager, JRG IDE, and the Matematika × JRG course.
