JRG 6 · Dasar JRG

Fungsi

Memberi nama pada sepotong pekerjaan, supaya bisa dipanggil berulang kali tanpa menyalin satu baris pun.

strukturBentuk dasar

BagianArtinya
fnKata kunci pembuka fungsi
luasPersegiNama — sebaiknya kata kerja atau menjelaskan hasilnya
(sisi: int)Parameter: nilai yang diterima dari pemanggil
-> intTipe nilai yang dikembalikan
returnNilai yang diserahkan kembali

Kenapa dipecah jadi fungsi?

Tiga alasan: tidak perlu menyalin kode, nama fungsinya menjelaskan maksud, dan kalau rumusnya berubah kamu cukup memperbaiki satu tempat.

Beberapa parameter

Nilai bawaan parameter

Parameter boleh punya nilai cadangan. Kalau pemanggil tidak mengisinya, yang dipakai nilai itu.

Fungsi tanpa nilai kembali

Tidak semua fungsi menghasilkan nilai. Sebagian hanya melakukan sesuatu — mencetak, misalnya.

Fungsi memanggil fungsi

Fungsi boleh memanggil fungsi lain, termasuk dirinya sendiri. Yang terakhir itu disebut rekursi.

Rekursi wajib punya rem

Baris if n <= 1 { return 1 } itulah remnya. Tanpa syarat berhenti, fungsi memanggil dirinya terus sampai JRG menghentikannya dan melaporkan kedalaman panggilan — bukan diam.

Urutan penulisan tidak mengikat

Fungsi boleh dipanggil sebelum baris deklarasinya. JRG membaca seluruh berkas dulu, baru menjalankan main.

Anotasi tipe tidak memaksa

Seperti di JRG 2: nama tipenya diperiksa, nilainya tidak. Fungsi bertanda float tetap menerima int.

Kuis 1

Apa gunanya return?

Tepat — dan ia sekaligus mengakhiri fungsi, jadi baris di bawahnya tidak dikerjakan.

return tidak mencetak apa pun; yang mencetak adalah wok.

Kuis 2

Kenapa fungsi rekursif perlu syarat berhenti?

Betul. Tanpa itu pemanggilan menumpuk sampai batas kedalaman tercapai.

Pikirkan apa yang terjadi kalau fungsi selalu memanggil dirinya.

Kuis 3

Bisakah fungsi dipanggil di baris sebelum ia ditulis?

Tepat.

Coba jalankan contoh 'urutan-fn.jrg' di atas — ia berjalan normal.

Latihan mandiri

1. Buat fungsi kubik(n) yang mengembalikan n³.

2. Buat fungsi maksimum(a, b) tanpa memakai math::max.

3. Buat fungsi rekursif yang menjumlahkan 1 sampai n.

Jawaban 1: return n * n * n, atau return n ** 3.
Jawaban 2: if a > b { return a } lalu return b.
Jawaban 3: if n <= 0 { return 0 } lalu return n + jumlah(n - 1).
