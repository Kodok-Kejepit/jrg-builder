Jebakan yang Paling Sering

Terlihat sepertiSebenarnya
for x in a memberi isi arrayMemberi indeks. Pakai for _, x in a untuk isinya.
7 / 2 = 3.5= 3. Dua bilangan bulat menghasilkan bilangan bulat.
1..=5 berisi 1 sampai 5Benar, tapi for n in 1..=5 tetap memberi indeks 0–4.

JRG Memanggil Bahasa Lain (FFI)

Kode yang sudah ditulis orang lain tidak perlu ditulis ulang. JRG bisa memanggilnya langsung — ini yang membuatnya bisa dipakai untuk pekerjaan nyata, bukan cuma latihan.

Kenapa Kotlin penting

Kotlin adalah bahasa utama untuk aplikasi Android, dan ekosistemnya besar. Karena Kotlin berjalan di atas JVM, JRG memanggilnya lewat jalan yang sama dengan Java — yang berbeda cuma NAMA yang dipakai kompilatornya: fungsi di berkas Hitung.kt mendarat di kelas HitungKt, dan object jadi field bernama INSTANCE.

Membuat aplikasi dengan JRG

Selain FFI, JRG punya dok:: — 119 fungsi untuk membuat aplikasi: router HTTP, WebSocket, SQLite, template yang melolosi HTML sendiri, cookie bertanda tangan, dan hash sandi. Contoh utuhnya ada di repo: examples/web_app_demo.jrg.
