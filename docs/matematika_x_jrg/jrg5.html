JRG 5 · Dasar JRG

Perulangan

Mengulang pekerjaan tanpa menyalin kode. Bab ini memuat satu hal khas JRG yang kalau tidak kamu tahu, programmu akan berjalan lancar sambil menjawab salah.

pentingHal pertama yang harus kamu tahu tentang for

Di banyak bahasa, for x in daftar memberikan isi daftarnya. Di JRG, ia memberikan nomor urutnya (indeks).

Kenapa ini berbahaya

Program di atas tidak error. Ia berjalan, mencetak angka, dan keluar dengan tenang — hanya saja angkanya salah. Kalau kamu memakainya untuk menjumlah nilai, kamu akan mendapat total dari 0+1+2, bukan dari nilai sebenarnya.

Bentuk yang mengikat isi-nya memakai dua nama, dipisah koma:

Kalau nomor urutnya tidak kamu butuhkan, tulis _ sebagai gantinya. Tanda itu berarti “ada, tapi sengaja tidak dipakai”.

Ditulisx berisiPakai kalau
for x in a0, 1, 2, … (indeks)kamu memang butuh nomor urut
for i, x in aindeks dan isibutuh dua-duanya
for _, x in aisi sajaini yang paling sering kamu mau

Rentang angka juga begitu

1..=5 membuat deretan lima angka. Tapi for n in 1..=5 tetap memberi indeks-nya — yaitu 0 sampai 4.

Aturan satu kalimat

Kalau nama sesudah for cuma satu, isinya selalu nomor urut — baik untuk array, string, maupun rentang. Butuh isinya? Pakai dua nama.

while — selama syarat masih benar

Pakai while kalau kamu tidak tahu berapa kali harus mengulang, hanya tahu kapan harus berhenti.

Perulangan yang tidak pernah berhenti

Kalau syarat while tidak pernah menjadi salah, programmu menggantung selamanya. Pastikan ada sesuatu di dalam badan yang mendekatkanmu ke syarat berhenti — di contoh atas, sisa mengecil tiap putaran.

Keluar lebih awal: break dan continue

Kata kunciArtinya
breakHentikan perulangan sekarang juga
continueLewati sisa badan, lanjut ke putaran berikutnya

Perulangan bersarang

Kuis 1

Apa yang dicetak for x in [10, 20, 30] { wok_(x, " ") }?

Tepat — satu nama berarti indeks. Ini jebakan JRG yang paling sering memakan korban.

Ingat aturannya: satu nama sesudah for selalu berisi nomor urut.

Kuis 2

Bagaimana cara menjumlahkan isi array a?

Betul. _ membuang indeksnya, x menerima isinya.

Pilihan pertama menjumlahkan indeks (0+1+2+…), bukan isinya — dan tidak ada yang memberitahumu.

Kuis 3

Apa beda break dan continue?

Tepat.

break menghentikan; continue melompati sisa badan putaran ini saja.

Latihan mandiri

1. Cetak semua bilangan genap dari 1 sampai 20.

2. Hitung berapa banyak angka di [3, 8, 12, 5, 20] yang lebih dari 6.

3. Cetak tabel perkalian 7 (7×1 sampai 7×10).

Jawaban 1: for _, n in 1..=20 { if n % 2 == 0 { wok_(n, " ") } }
Jawaban 2: pakai penghitung var c = 0, lalu for _, n in a { if n > 6 { c += 1 } } → 3.
Jawaban 3: for _, i in 1..=10 { wok("7 x", i, "=", 7 * i) }
