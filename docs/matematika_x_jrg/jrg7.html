JRG 7 · Dasar JRG

Array & Teks

Menyimpan banyak nilai dalam satu nama, dan mengolah kalimat. Dua tipe yang paling sering kamu pakai sesudah angka.

koleksiArray: deretan nilai

Nomor mulai dari nol

Elemen pertama ada di posisi 0, bukan 1. Jadi array berisi 4 elemen punya posisi 0, 1, 2, 3 — dan nilai[4] adalah galat.

JRG punya jalan pintas untuk posisi dari belakang: angka negatif.

Di luar jangkauan selalu galat

JRG tidak pernah diam-diam mengembalikan nilai kosong untuk posisi yang tidak ada. Ia berhenti dan menyebutkan panjang sebenarnya — jauh lebih baik daripada program yang lanjut membawa nilai palsu.

Mengiris array

Fungsi bawaan untuk array

FungsiHasilnyaCatatan
arr::sum(a)Jumlah semua isiint kalau isinya int
arr::mean(a)Rata-rataselalu float
arr::max(a) / minTerbesar / terkecilmempertahankan tipe
arr::sort(a)Urutan menaikmenghasilkan array baru
arr::contains(a, x)Ada isinya atau tidaktrue/false
arr::push(a, x)Array baru + satu elemenyang lama tidak berubah

Array tidak pernah berubah diam-diam

Lihat baris terakhir: sesudah arr::sort, isi n masih seperti semula. Di JRG setiap nilai dimiliki satu nama; fungsi menghasilkan array baru. Kalau mau menyimpan hasilnya, tugaskan kembali: n = arr::sort(n).

Teks (string)

Menyambung teks memakai +. Kalau salah satu sisinya angka, angkanya diubah jadi teks.

Menyusun teks rapi dengan str::format

Tanda {} diisi berurutan oleh nilai-nilai sesudahnya. Untuk membatasi angka di belakang koma, pakai {:.N}.

Kapan pakai {:.2}

Setiap kali kamu menampilkan uang, nilai rapor, atau ukuran. Tanpa itu 1/3 tampil sebagai 0.3333333333333333 — benar, tapi tidak enak dibaca.

Memecah dan menggabung

Kuis 1

Posisi elemen pertama sebuah array adalah?

Tepat. Elemen pertama ada di posisi 0.

Di JRG (seperti kebanyakan bahasa) penomoran dimulai dari nol.

Kuis 2

Sesudah arr::sort(n), apakah isi n ikut terurut?

Betul. Simpan hasilnya kalau kamu memerlukannya: n = arr::sort(n).

Coba jalankan contoh arr.jrg di atas dan lihat baris terakhirnya.

Kuis 3

Apa hasil str::format("{:.1}", 3.456)?

Tepat — satu angka di belakang koma, dan nilainya dibulatkan.

{:.1} membulatkan ke satu angka di belakang koma.

Latihan mandiri

1. Dari [12, 7, 25, 3], cetak selisih terbesar dan terkecil.

2. Hitung berapa huruf pada kalimat "Saya belajar JRG" tanpa menghitung spasi.

Jawaban 1: arr::max(a) - arr::min(a) → 22.
Jawaban 2: len(str::replace(s, " ", "")) → 14.
