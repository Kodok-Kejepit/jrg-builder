JRG 4 · Dasar JRG

Percabangan: if & match

Membuat program memilih jalan. Dua cara: satu untuk syarat bebas, satu untuk mencocokkan nilai.

logikaif — kalau begini, lakukan itu

Tanpa kurung di syaratnya

Berbeda dari C atau Java, syarat if di JRG tidak perlu dibungkus kurung. Yang wajib justru kurung kurawal { }-nya, bahkan untuk satu baris — itu menutup satu kelas bug klasik.

Beberapa cabang

Urutannya penting

Cabang diperiksa dari atas. Kalau n >= 70 ditaruh paling atas, nilai 95 akan berhenti di situ dan dapat “C”. Susun dari syarat yang paling ketat.

if juga menghasilkan nilai

Di JRG, if bukan cuma pernyataan — ia bisa dipakai langsung sebagai nilai.

Bentuk singkat: $

Untuk pilihan sederhana ada bentuk ringkas syarat $ a : b. Bacanya: “kalau syarat, ambil a, kalau tidak b”. Pembukanya $, bukan ? — tanda tanya di JRG dipakai untuk hal lain.

match — mencocokkan nilai

Kalau kamu membandingkan satu nilai dengan banyak kemungkinan, match jauh lebih rapi daripada tumpukan else if.

PolaCocok dengan
3Nilai tepat 3
6 | 76 atau 7
1..=5Rentang 1 sampai 5
n if n > 100Nilai apa pun, asal lebih dari 100
_Apa pun — taruh paling bawah

match harus mencakup semua kemungkinan

Kalau ada nilai yang tidak tertangkap satu pun pola, JRG menolak programnya — bukan diam lalu menghasilkan nilai kosong. Itulah gunanya _ di baris terakhir.

Kuis 1

Apa hasil if 5 > 3 { "ya" } else { "tidak" }?

Tepat — di JRG if menghasilkan nilai dari cabang yang terpilih.

if di JRG bisa dipakai sebagai nilai, dan yang keluar adalah isi cabangnya.

Kuis 2

Kenapa _ ditaruh paling bawah di match?

Betul. Pola diperiksa dari atas, jadi _ di atas akan menelan semuanya.

Pikirkan urutan pemeriksaannya — dari atas ke bawah.

Kuis 3

Pembuka bentuk ringkas percabangan di JRG adalah?

Tepat: syarat $ a : b. Tanda ? dipakai untuk penerusan galat.

Bukan ? — di JRG tanda itu punya tugas lain.

Latihan mandiri

1. Tulis fungsi yang menerima angka dan mengembalikan "positif", "negatif", atau "nol".

2. Tulis ulang fungsi itu memakai match.

Jawaban 1: tiga cabang if/else if/else, periksa > 0 lalu < 0.
Jawaban 2: match n { 0 => "nol", x if x > 0 => "positif", _ => "negatif" }.
