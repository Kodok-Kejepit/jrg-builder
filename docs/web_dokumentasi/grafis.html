Pustaka

Kanvas, suara, dan numerik

Menggambar dan menyimpan PNG, membuat bunyi, dan menghitung dengan array numerik.

Kanvas

Canvas::new(lebar, tinggi) membuat bidang gambar. Warna ditulis 0xRRGGBB, dan titik (0, 0) ada di kiri atas.

Yang tersedia (57 fungsi, semuanya juga bisa dipanggil sebagai method):

  • Bentuk: garis (biasa dan anti-alias), persegi, persegi bersudut tumpul, lingkaran, elips, busur, segitiga, poligon, kurva Bezier, dan teks berskala.
  • Isian: warna polos, gradien linear, dan gradien radial.
  • Transformasi: translate, rotate, scale, dengan tumpukan push/pop, dan pemotongan clip.
  • Gambar: save_png, save_bmp, Canvas::load_png, serta blit/blit_region untuk menempel kanvas lain (sprite, petak).
  • Masukan: tombol keyboard, tetikus, dan sentuhan, untuk kanvas yang punya jendela.

Jendela

Argumen keempat Canvas::new memilih tempat tampilnya:

ModeHasil
"polos" (bawaan)tanpa jendela; gambar disimpan ke berkas
"tab"jendela desktop (butuh build --features canvas)
"web"tampil di peramban lewat server lokal
"png"tiap bingkai ditulis jadi berkas PNG

Putaran animasinya: selama c.is_open(), gambar, lalu panggil c.update(). c.delta_time() memberi lama bingkai terakhir dalam detik. Untuk game, lebih enak memakai mesin game.

Suara

suara:: membuat bunyi sebagai array sampel (mono, 44.100 Hz), menyimpannya sebagai WAV, dan memutarnya lewat PulseAudio atau PipeWire.

suara::putar(bunyi) memutar tanpa menunggu, putar_tunggu menunggu sampai selesai. suara::tersedia() memberi tahu apakah ada keluaran audio. Fungsi lain: derau, selubung (fade in/out), dan muat_wav.

Numerik: wokwok

wokwok:: punya array n-dimensi sendiri yang isinya disimpan rapat dalam satu jenis angka. Untuk perhitungan elemen per elemen atas data besar, ia jauh lebih cepat daripada array biasa.

Ada 86 fungsi: pembuat array (zeros, ones, eye, linspace, random), operasi elemen per elemen, agregat (sum, mean, std, var, argmax), bentuk (reshape, transpose, flatten), dan aljabar linear (dot, matmul, inv, det, solve). Penjumlahannya memakai cara berpasangan, jadi sejuta angka 0.1 berjumlah tepat 100000.

Statistik dan matriks kecil

Untuk data yang berupa array biasa, dok:: punya statistik (stat_percentile, stat_linreg, stat_correlation, stat_normal_cdf), vektor (vec_dot, vec_cross, vec_normalize), matriks (mat_mul, mat_inverse, mat_det), dan teori bilangan (num_is_prime, num_prime_factors, num_mod_pow).
