Pola di let dan for

Pola juga dipakai di let, di kepala for, dan di parameter fungsi.

let … else

Kalau polanya mungkin tidak cocok, let pola = nilai else { … } menjalankan blok else. Blok itu harus keluar dari alurnya (return, break, atau continue), jadi sesudah baris itu nama-namanya pasti terisi.

??

a ?? b membuka sebuah Option: isinya kalau Some, b kalau None. Sisi kanan cuma dihitung kalau dibutuhkan.

Varian telanjang

Di dalam berkas yang mendeklarasikan sebuah enum, variannya boleh ditulis tanpa nama tipenya, asal tidak ada enum lain di berkas itu yang punya varian bernama sama.
