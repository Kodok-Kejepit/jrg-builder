Perkakas

Editor, REPL, dan IDE

Penyunting di terminal, server bahasa untuk editor favoritmu, dan JRG IDE yang jalan di peramban dan HP.

jrgedit

jrgc --sunting membuka penyunting layar penuh bergaya nano. Penyunting ini ditulis dalam JRG dan ikut di dalam jrgc, jadi selalu tersedia.

TombolGunanya
Ctrl+S / Ctrl+Qsimpan / keluar
Ctrl+Z / Ctrl+Yurung / ulang
Ctrl+F / Ctrl+Pcari / ganti
Ctrl+Rsimpan lalu jalankan; sesudahnya kursor pindah ke letak galat
Alt+Pperiksa tanpa menjalankan
Ctrl+Obuka berkas lain; Alt+panah pindah berkas
Shift+panah, Ctrl+C/X/Vpilih, salin, potong, tempel
F1 atau Escdaftar tombol lengkap

Ada penyorotan sintaks, kurung yang menutup sendiri, indentasi yang mengikuti baris sebelumnya, dan tetikus.

REPL

jrgc tanpa argumen membuka REPL. Panah atas/bawah menelusuri riwayat, blok yang belum tertutup dilanjutkan otomatis, dan galat tidak mengakhiri sesi.

PerintahGunanya
:cari kata, :doc nama, :daftar nsmenemukan fungsi bawaan
:tipe ekspresitipe tanpa mencetak nilainya
:simpan berkas.jrgtulis sesi jadi program yang bisa dijalankan
:riwayat, :hapus, :keluarriwayat, mulai ulang, keluar

Server bahasa (LSP)

jrgc --lsp (atau jrgm lsp) adalah server Language Server Protocol. Editor yang mendukung LSP mendapat: galat dan peringatan sambil mengetik, pelengkapan nama (termasuk seluruh fungsi bawaan), keterangan saat kursor di atas nama, lompat ke definisi, dan daftar simbol berkas.

Contoh untuk Neovim:

Di VS Code, pakai ekstensi LSP generik dengan perintah jrgc --lsp untuk berkas *.jrg.

JRG IDE

JRG IDE adalah lingkungan pengembangan di peramban, dan dibuat dengan JRG sendiri. Isinya penyunting dengan penyorotan dan pelengkapan, panel Masalah (galat dan peringatan lint), terminal, pohon berkas, proyek jrgm, dan tombol Jalankan untuk JRG serta bahasa lain.
