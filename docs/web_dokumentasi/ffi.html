Pustaka

Bahasa lain (FFI)

Memanggil C, C++, Rust, Go, Python, JavaScript, PHP, Lua, Java, Kotlin, .NET, dan WebAssembly dari JRG.

Semua pintu ke bahasa lain menjawab Result: pustakanya bisa saja tidak terpasang, dan itu kegagalan yang wajar ditangani.

C, Rust, dan Go

Deklarasikan tanda tangannya di blok extern "C", lalu panggil seperti fungsi biasa. Nama pustaka boleh disebut.

Rust (#[no_mangle] pub extern "C" fn) dan Go (-buildmode=c-shared dengan //export) menghasilkan simbol C biasa, jadi dipanggil dengan cara yang sama.

C++

extern "C++" menghitung sendiri nama simbol C++ (mangling) dari tanda tangannya, jadi pustaka C++ bisa dipanggil tanpa membungkusnya. Fungsi di dalam namespace ditulis dengan jalurnya.

Python

py:: menjalankan Python di proses terpisah dan berbicara dengannya, jadi pustaka apa pun yang bisa di-import bisa dipakai: numpy, pandas, requests, PIL, dan seterusnya.

  • Nilai yang punya padanan (angka, teks, list, dict) datang sebagai nilai JRG biasa. Yang tidak punya (set, objek, DataFrame) datang sebagai handle: method-nya bisa dipanggil (df.head(5)), ia bisa dioper lagi ke Python, dan dilepas sendiri saat tidak dipakai.
  • py::ref(kode) meminta handle walau nilainya bisa dikonversi, supaya data besar tetap di sisi Python.
  • Fungsi JRG boleh jadi callback (map, sorted(key=…), df.apply), juga dari thread Python lain.
  • Argumen bernama lewat py::call_kw dan py::method_kw.

JavaScript, PHP, dan Lua

Tiga-tiganya memakai mesin yang sama dengan py::, jadi aturannya sama: nilai atau handle, fungsi JRG sebagai callback, dan Result di setiap panggilan.

  • js:: butuh Node. Promise ditunggu otomatis, jadi fetch dan pustaka async bisa dipakai apa adanya.
  • php:: butuh PHP 8. Peringatan PHP menjadi Err, echo dialihkan ke stderr, dan pustaka Composer dimuat dengan php::require("vendor/autoload.php").
  • lua:: butuh Lua 5.3 ke atas.

Java dan Kotlin

jvm:: memuat JVM dari JDK yang terpasang lewat JNI. Tanda tangan metode ditulis sebagai deskriptor JNI, persis seperti yang dicetak javap -s.

kotlin:: menerjemahkan aturan nama Kotlin ke JVM: fungsi tingkat atas (kotlin::fungsi("Hitung", "tambah", …)), object (kotlin::objek), properti (kotlin::properti), dan companion.

.NET

Metode yang dipanggil harus bertanda [UnmanagedCallersOnly]; sesudah itu ia diperlakukan seperti fungsi C.

WebAssembly

wasm:: menjalankan modul .wasm dengan interpreter yang ada di dalam JRG sendiri. Modulnya cuma bisa menyentuh memorinya sendiri, jadi cocok untuk menjalankan kode dari luar yang tidak sepenuhnya dipercaya.

Fitur WASM yang belum didukung (impor, call_indirect, SIMD) ditolak saat dimuat, dengan nama fiturnya.
