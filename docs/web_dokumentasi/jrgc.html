Native compilation

--emit-llvm translates the program to LLVM IR and hands it to clang. The native runtime is built once with cargo and cached.

FlagWhat it is for
-O 0..3optimisation level (default 2)
--lto auto|off|thin|full, --lldlink-time optimisation
--native-cpu, --fast-math, --aggressivefaster, each with its own conditions
--pgo-generate, --pgo-useprofile-guided optimisation
--strip, --no-gc-sectionsbinary size

The native backend does not accept the whole language yet; what is missing is refused with its reason. See The engines.

WebAssembly (in progress)

A fifth engine is being built: it compiles a JRG program to a WebAssembly module, through the same LLVM IR as --emit-llvm, so the program can run in a browser or under Node. It is not released yet; the engines page is where it will be announced.
