Memeriksa tanpa menjalankan

Tes dan profil

Mencari fungsi

Kompilasi native

--emit-llvm menerjemahkan program ke LLVM IR lalu menyerahkannya ke clang. Runtime native-nya dibangun sekali dengan cargo dan disimpan.

BenderaGunanya
-O 0..3tingkat optimisasi (bawaan 2)
--lto auto|off|thin|full, --lldoptimisasi saat menautkan
--native-cpu, --fast-math, --aggressivelebih cepat, dengan syaratnya masing-masing
--pgo-generate, --pgo-useoptimisasi berdasarkan profil pemakaian
--strip, --no-gc-sectionsukuran biner

Backend native belum menerima seluruh bahasa; yang belum ada ditolak dengan alasannya. Lihat Tiga mesin.
