Pustaka

Mesin game

std/mesin, mesin game 2D di atas kanvas, yang bisa diuji tanpa membuka jendela.

import "std/mesin" memberi mesin game 2D yang ditulis dalam JRG. Sebuah game terdiri dari tiga hal: keadaan awal, fungsi perbarui yang menghitung keadaan berikutnya, dan fungsi gambar.

Game terkecil

Di komputer yang punya layar, g.jalankan() membuka jendela dan bola bisa digeser dengan panah. Di tempat lain, simulasi memajukan game dua langkah dengan tombol Right ditahan, lalu mencetak posisinya.

Tiga aturan

  1. Keadaan adalah nilai. perbarui(keadaan, masukan, dt) mengembalikan keadaan baru; tidak ada yang diubah di tempat. Karena itu game bisa diputar ulang dan diuji.
  2. Langkah waktu tetap, bawaannya 1/60 detik (ubah dengan dengan_dt). Fisikanya sama di komputer cepat dan lambat.
  3. Bisa jalan tanpa jendela. simulasi(rekaman) menerima daftar tombol yang ditahan di tiap langkah. dengan_rekam() merekam permainan sungguhan, dan putar(rekaman) mengulangnya sampai ke keadaan yang sama, jadi bug yang muncul saat bermain bisa dijadikan tes.

Field struct keadaan perlu pub, karena perbarui dan gambar adalah fungsi biasa, bukan method.

Di HP

Tombol layar digambar di pita bawah layar dan dibaca seperti tombol keyboard, jadi perbarui tidak perlu diubah. Game JRG bisa dibungkus jadi APK dengan jrgm apk (lihat Aplikasi Android).
