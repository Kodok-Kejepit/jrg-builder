Perkakas

jrgm

Mengurus proyek: membuat, menjalankan, menguji, merapikan, memeriksa, dependensi, dan rilis.

Proyek baru

Isinya:

jrgm new nama --kind lib membuat pustaka, --kind web membuat aplikasi web, dan --android menambahkan bagian [android]. Proyek bahasa lain juga bisa: jrgm new alat --bahasa python (juga javascript, c, cpp, rust, go, java, php, lua, ruby, sh); run, build, test, dan fmt lalu memakai perkakas bahasa itu.

Perintah

PerintahGunanya
jrgm run [--vm] [--watch]jalankan proyek; --watch mengulang tiap ada yang berubah
jrgm test [--filter kata] [--vm]jalankan tes di tests/*.jrg
jrgm buildperiksa semua berkas proyek dan dependensinya
jrgm checkperiksa titik masuk saja
jrgm fmt [--check]rapikan spasi dan indentasi tiap berkas
jrgm lint [--ketat]galat ditambah peringatan
jrgm exec berkasjalankan satu berkas tanpa proyek (.jrg, .c, .py, .rs, .go, …)
jrgm cleanhapus hasil bangun
jrgm lspserver bahasa untuk editor
jrgm apk, jrgm kunci, jrgm siapkan androidaplikasi Android, lihat Aplikasi Android

Tes

Fungsi bernama test_… atau uji_… di tests/*.jrg adalah tes. Tiap berkas jalan di prosesnya sendiri dengan batas waktu, jadi satu tes yang macet tidak menahan yang lain.

Lint

Peringatannya: import yang tidak dipakai, fungsi yang tidak pernah dipanggil, variabel yang tidak pernah dibaca, literal bulat di tempat pecahan, dan berkas yang belum rapi. --ketat membuat peringatan menggagalkan perintahnya.

Dependensi

Dependensi bisa berupa folder lokal atau repositori git. Git berperan sebagai registri: versinya adalah tag v<versi>, dan commit yang dipakai dikunci di jrgm.lock.

Sesudah ditambahkan, modul dependensi bisa langsung di-import "bantu". Siklus dependensi dan dua dependensi yang memberi nama modul sama ditolak dengan rantainya disebut.

Menerbitkan

Proyek lain lalu bisa memakainya dengan jrgm add nama --git url --version x.y.z. jrgm add nama tanpa --path atau --git ditolak, karena belum ada registri pusat untuk mencari nama saja.
