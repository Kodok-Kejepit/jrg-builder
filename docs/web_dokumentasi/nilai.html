Nilai dan tipe

Angka, teks, array, tuple, dict, dan cara mengikatnya ke nama.

Mengikat nama

BentukBisa ditugasi ulang?
let x = 1tidak
const X = 1tidak
var x = 1ya
x := 1ya, sekaligus mendeklarasikan
let mut x = 1ya, sama dengan var

Nama harus dideklarasikan sebelum ditugasi. totl = 5 atas nama yang belum ada ditolak, jadi salah ketik tidak diam-diam membuat variabel baru. Nama yang diikat let juga tidak bisa diubah isinya: let a = [1, 2] lalu a[0] = 9 ditolak.

Anotasi tipe boleh ditulis (let n: int = 5), dan JRG memeriksa bahwa nama tipenya ada. Isinya tidak ditegakkan: JRG diketik dinamis, jadi anotasi berfungsi sebagai dokumentasi.

Angka

int adalah bilangan bulat 128 bit, float pecahan 64 bit. Pembagian dua int menghasilkan int (dipotong ke arah nol), dan % adalah sisa bagi.

Luapan tidak membungkus diam-diam. 170141183460469231731687303715884105727 + 1 adalah galat, begitu juga pembagian dengan nol. Untuk aritmetika yang memang ingin membungkus (hash, pembangkit acak), pakai math::wrap_add, math::wrap_sub, dan math::wrap_mul.

Tipe bulat berlebar tetap juga ada: i8 sampai i128, u8 sampai u128, isize, usize, dan byte (bilangan 0–255). Pecahan: f32, f64.

Teks

string adalah teks UTF-8. Indeks menghitung karakter, bukan byte, dan satu karakter bertipe rune (ditulis 'a').

Ada tiga cara menulis teks literal:

"""…""" dan «…» adalah template: isi ${…} dihitung lalu disisipkan, dan boleh lebih dari satu baris. Backtick menghasilkan teks mentah tanpa escape dan tanpa penyisipan.

Array

Array berisi nilai berurutan. Indeks negatif menghitung dari belakang, dan indeks di luar batas selalu galat.

Method yang "mengubah" seperti push mengembalikan array baru; tugaskan hasilnya kembali (a = a.push(x)). Bentuk ini tidak menyalin seluruh array, jadi menambah elemen satu per satu tetap cepat.

Yang mungkin tidak menemukan apa pun (first, last, get, find, pop) mengembalikan Option, tidak pernah nil atau -1. Lihat Option dan Result.

Tuple

Tuple mengelompokkan beberapa nilai dengan tipe berbeda. Elemennya dibaca dengan .0, .1, atau [i], dan bisa dibongkar ke beberapa nama sekaligus.

Dict

Dict memetakan kunci ke nilai. Kuncinya disimpan sebagai teks, jadi d[1] dan d["1"] menunjuk tempat yang sama. Urutan cetaknya urut kunci.

Membaca kunci yang tidak ada lewat d[k] adalah galat; pakai dict::get (mengembalikan Option) atau get_or.

Konversi

as mengubah tipe dasar. Konversi yang tidak punya jawaban tepat ditolak, bukan dipotong diam-diam.

300 as u8, -1 as uint, dan int("abc") adalah galat. Untuk mengambil 8 bit terbawah, tulis x & 255.

Nilai kosong

nil ada, tapi jarang dibutuhkan. Fungsi bawaan yang bisa tidak menemukan sesuatu menjawab Option::None, dan var x: int tanpa nilai awal mendapat nilai nol tipenya (0, 0.0, "", false, []).
