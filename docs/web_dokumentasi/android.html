Aplikasi Android

Membungkus program atau proyek JRG jadi APK, dari game kanvas sampai aplikasi berantarmuka web.

Dari proyek

Identitas aplikasinya ditulis di jrgm.toml:

Dua jenis tampilan

tampilanIsinyaCocok untuk
"kanvas" (bawaan)program dikompilasi native lewat LLVM, menggambar ke layar penuhgame, gambar, alat sederhana
"web"jrgc ikut di dalam APK dan menjalankan proyekmu sebagai server lokal; halamannya tampil di WebViewaplikasi dengan antarmuka HTML

Proyek dari jrgm new x --kind web sudah memakai tampilan web. Di sana seluruh bahasa dan pustaka tersedia, karena yang menjalankannya interpreter yang sama dengan di komputer. Halamannya juga mendapat objek JRGAndroid untuk meminta izin (mintaIzin("kamera")), menggetarkan HP, dan bertukar berkas dengan penyimpanan HP.

Tampilan kanvas memakai backend LLVM, jadi berlaku batasan backend itu (lihat Yang belum jadi).

Izin

izin = [...] menerima internet, jaringan, wifi, getar, tetap_menyala, latar (jalan di latar dengan notifikasi), serta izin yang perlu dialog di tampilan web: kamera, mikrofon, lokasi, kontak, penyimpanan, telepon, sms, kalender. Nama izin Android lengkap (android.permission.X) juga diterima.

Bahasa dan pustaka native di dalam APK

jrgm mengunduh sumber resminya sekali (sidiknya diperiksa), lalu mengompilasinya untuk tiap ABI. Pustaka native dipanggil dari JRG lewat extern "C" "libhitung.so" { … }.

Rilis ke Play Store

APK biasa ditandatangani dengan kunci debug. Simpan berkas kunci rilis baik-baik: tanpa kunci yang sama, pembaruan aplikasi tidak bisa dipasang di atas versi lama.
