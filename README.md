# jrg-builder

Repo ini **khusus untuk membangun dan menguji JRG (JawaRustGo++)** lewat GitHub Actions — kompilasi, suite tes
lengkap, sapuan contoh, dan sapuan sanitizer runtime LLVM. Isinya salinan kode yang sedang diuji, didorong apa
adanya; bukan tempat pengembangan, jadi issue dan pull request tidak diproses di sini.

- Kode sumber dan rilis resmi: https://github.com/Kodok-Kejepit/jrg
- Dokumentasi: https://jrg-lang.org
